Personal Expense Tracker
A simple menu-based Python program to track daily spending.
Created by: Ritesh Agrahari
Course: BCA
Features
Add, view and delete expenses
See total money spent
Find the highest expense
Set and check a monthly budget (with a warning when you cross it)
See your savings (income minus expenses)
Starts with sample income, budget and expenses
How to Run
Install Python 3 from python.org
Download expense_tracker.py
Open a terminal in that folder and run:
python expense_tracker.py
Menu
1. Add Expense
2. View Expenses
3. Delete Expense
4. Total Spent
5. Set Budget
6. Check Budget
7. Highest Expense
8. Savings
9. Exit
Concepts Used
Lists
while loop and for loop
if / elif / else
Input validation
Built-in functions: sum(), max(), len()
